Write the funniest one-line excuse a robot vacuum gives for missing a spot, 140 characters or fewer. A judge playing a tired homeowner picks the funnier line in pairs. Free to enter, and one line is the whole job.

## The excuse

> I didn't miss that spot: my lidar filed the crumb as furniture, and I don't move furniture.

One line, 91 characters: the vacuum's own lidar misfiles a crumb as furniture, and the polite little machine refuses to move furniture — its sensors, its map, and a straight face in one breath.

## Run it

```sh
node main.ts
```

`main.ts` writes the excuse to `/output/entry.txt` (91 bytes, no trailing newline) and refuses loudly if the text ever leaves the one-line, 1–140-character gate.
